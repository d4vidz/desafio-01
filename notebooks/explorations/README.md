# Exploratory notebooks

Use this directory for bounded experiments that may inform the final notebook, such as baseline-model comparisons or genre-aware sensitivity checks.

`musical_structure.py` is the independent PCA/clustering track. It produces bounded figures and a compact evidence table for human review; it does not make claims about listener segments or natural clusters without stability support.

An exploratory result is not a final conclusion until its data contract, evaluation, visualization, and caveats are incorporated into `../spotify_analysis.py`.
